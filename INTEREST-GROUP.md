# GHOST Evaluation Interest Group

This repository includes a **public, GitHub-native interest group** for the planned GHOST Technical Evaluation.

## What joining means

A participant who joins is publicly stating, in substance:

> I have seen the planned **USD 2,000** reference price. If the GHOST Technical Evaluation becomes available on substantially the described terms, I currently intend to consider purchasing access and I want to remain in the public interest group while availability is pending.

Joining does **not** require payment and does **not** create a binding purchase obligation, reservation, contract, or guarantee of access.

## Where the group lives

The group stays entirely inside this GitHub repository:

**Discussions → Evaluation Interest**

Each participant creates one discussion entry using the repository's structured **Evaluation Interest** form. The category itself becomes the visible public list of interested GitHub users / organizations.

No external waitlist, email form, checkout, landing page, or third-party signup is required.

## One account, one interest entry

For clean demand measurement, participants should create only one active Evaluation Interest entry per GitHub account or represented organization.

The useful signal is not stars or casual comments. It is the number and quality of people who knowingly join after seeing the planned evaluation price and scope.

## Public-information warning

Evaluation Interest discussions are public. Do not post:

- passwords, credentials, tokens, or private keys;
- classified, controlled, or restricted information;
- sensitive network topology;
- exploit details or unpatched vulnerability information;
- confidential procurement or commercial information.

Security-sensitive reports should use GitHub's private vulnerability reporting feature if enabled.
