# Repository Contact Paths

GHOST keeps public project interaction inside this GitHub repository.

## Join the Evaluation Interest Group

Use:

**Discussions → Evaluation Interest**

This is the public repository-native group/list for people or organizations who have seen the planned **USD 2,000** evaluation reference price and want to remain on the interest list until evaluation availability is announced.

## Other questions

Use:

**Issues → New issue → Evaluation / Collaboration Interest**

for non-sensitive technical, integration, licensing, or collaboration questions.

Do not post confidential or security-sensitive information publicly.
