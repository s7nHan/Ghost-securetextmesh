# Sanitized Validation Outputs

This folder contains text-only public extracts from the GHOST validation archive.

Current files:

- `public-validation-summary.txt` — summarized validation snapshot;
- `three-node-e2e-pass.txt` — sanitized strict-production 3-node E2E result.

The extracts intentionally omit private filesystem paths, source listings, secrets, key material, sensitive configuration and other implementation-sensitive details.
