# GHOST Technical Evaluation

GHOST is being presented publicly as a technical showcase while the production implementation remains private.

## Planned reference evaluation price

**USD 2,000**

This is a reference price for a future limited, time-bound technical evaluation package. It is not a public checkout or current offer for immediate delivery.

## When the first access window is expected

The repository begins with an initial **1–2 week public demand-validation period**.

During that period, the project measures several different signals:

- GitHub stars as a visibility / technical-interest signal;
- Issues and Discussions as deeper technical or integration engagement;
- **Evaluation Interest** entries as the strongest repository-native signal of qualified intent around the planned paid evaluation.

If sufficient genuine interest is confirmed and the release gate remains ready, the first controlled demo / Technical Evaluation access window will be announced and opened. No fixed calendar date is promised in advance, and a star count alone is not an automatic release trigger.

## Expected evaluation scope

A controlled evaluation may include, depending on the participant and final terms:

- Time-limited access
- Controlled evaluation build and/or private source access where appropriate
- Technical documentation
- Multi-node test guidance
- Setup / installation guidance
- Defined technical support window
- Evaluation-only rights
- No production deployment rights unless separately agreed
- No redistribution rights

## Evaluation Interest Group

The repository contains a public, GitHub-native **Evaluation Interest Group**.

To join:

1. Open the repository **Discussions** tab.
2. Open **Evaluation Interest**.
3. Create one entry using the structured form.
4. Confirm that you have seen the planned **USD 2,000** reference price and want to remain in the public interest group while evaluation availability is pending.

The category itself acts as the visible interest list. No external website, email list, waitlist service, or payment flow is used.

Joining is non-binding and requires no payment. It records purchase/evaluation intent for demand measurement; it is not an order, reservation, contract, or guarantee of access.

See [Evaluation Interest Group](INTEREST-GROUP.md) for the exact meaning of membership.

## Separate Issues channel

GitHub **Issues** remains available for technical, integration, licensing, collaboration, and other non-sensitive questions. Joining the Evaluation Interest Group is separate from opening an Issue.

## Public-information warning

GitHub Discussions and Issues are public unless repository settings say otherwise. Do **not** post:

- passwords or credentials;
- private keys;
- classified or restricted information;
- sensitive network topology;
- exploitable security details;
- confidential commercial information.

For sensitive security findings, use GitHub's private vulnerability reporting feature if it is enabled for the repository.
