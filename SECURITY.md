# Security Policy

This repository is a public technical showcase. The production implementation is not published here.

## Reporting a security concern

If GitHub **Private Vulnerability Reporting** is enabled for this repository, use the repository's **Security → Report a vulnerability** flow for sensitive findings.

Do not place exploit details, credentials, private keys, sensitive infrastructure information, or confidential material in a public Issue or Discussion.

For non-sensitive questions about the public documentation, use GitHub Issues.

## Scope

Public documentation and sanitized validation artifacts are provided for technical review. They do not constitute an independent security audit or certification.
